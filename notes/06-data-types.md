# Data Types

There are 2 data subsets:
1. Scalar
2. Compound

## Scalar types
1. integers
2. floats
3. booleans
4. characters

### Integers
There are different types of integers as well.

Each signed variant can store numbers from −(2n − 1) to 2n − 1 − 1 inclusive, n here is the number of bits that variant uses.
